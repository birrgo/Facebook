GitHub Workflow Trigger (Admin)

Stored locally in this browser (localStorage) so you can trigger autoposter.yml on demand without waiting 5 minutes. Requires a GitHub Fine-Grained PAT with Actions: Read & write on birrgo/Facebook.

1. Add & Manage Facebook Pages

2. Upload Image or Video (Max 200 MB) & Schedule Post

3. Active & Scheduled Queue

Media is uploaded to Firebase Storage and automatically deleted after posting to save storage.

4. All Posted Items

Shows all posted items and lets you remove any leftover queue/storage entries to save storage.
