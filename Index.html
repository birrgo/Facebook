Facebook Multi-Page Auto Poster (Realtime DB Only)

Admin Sign In

GitHub Workflow Trigger (Admin)

Managed manually from admin controls via workflow_dispatch on autoposter.yml. Saved to Firebase Realtime Database (workflowConfig) and cached locally in this browser. Requires a GitHub Fine-Grained PAT with Actions: Read & write on birrgo/Facebook.

1. Add & Manage Facebook Pages

2. Schedule Video (by URL) or Image (to Realtime DB)

Because Firebase Storage is disabled, videos are saved by direct URL in Realtime Database, while images are compressed and saved directly to Realtime Database.
Adds distinct context or a discussion prompt for each selected Page instead of sending byte-for-byte identical copy everywhere.

3. Active & Scheduled Queue

Entries are stored in Firebase Realtime Database under scheduledPosts.

4. All Posted Items

Shows all posted items recorded in Realtime Database.
